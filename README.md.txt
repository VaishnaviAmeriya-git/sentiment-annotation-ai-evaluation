# Sentiment Annotation & AI Output Quality Evaluation

## Overview
A portfolio project demonstrating a human-in-the-loop workflow for sentiment annotation, quality assurance, and evaluation of AI-generated sentiment predictions.

## Objectives
- Manually annotate text samples
- Apply consistent annotation guidelines
- Perform quality review
- Compare human labels with AI predictions
- Analyze sentiment and confidence distributions

## Dataset
- 100 English text samples
- Labels: Positive, Negative, Neutral, Mixed
- Confidence levels: High, Medium, Low

## Tools
- Python
- Google Sheets
- Pandas
- Hugging Face Transformers

## Workflow
1. Annotation Guidelines
2. Manual Annotation
3. Quality Review
4. AI Evaluation
5. Dashboard Analysis

## Skills Demonstrated
Data Annotation · Sentiment Analysis · Quality Assurance · Text Classification · AI Evaluation
